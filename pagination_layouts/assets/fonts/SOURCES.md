# Font assets for canonical pagination

The layout registry validates every font and license file by SHA-256 before Chromium starts.
There is no system-font fallback.

The `helios_pagination_layout@1` assets are the variable Noto Sans and Noto Serif fonts published
by the Google Fonts repository under the SIL Open Font License 1.1. The exact downloaded bytes,
paths, and hashes are frozen in `pagination_layouts/helios_pagination_layout_v1.yaml`.

Upstream locations:

- `https://github.com/google/fonts/tree/main/ofl/notosans`
- `https://github.com/google/fonts/tree/main/ofl/notoserif`
