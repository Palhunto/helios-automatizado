# Prompts

`registry.yaml` é o único registro oficial de resolução de prompts.

## Regras

- código referencia `id + version`;
- registry referencia arquivo + SHA-256;
- snapshot de produção é imutável;
- projeto iniciado congela as versões usadas;
- wrappers técnicos futuros ficam separados dos prompts editoriais.

Prompts OmegaBrain atuais:
- `omega_academic_planning@1`
- `omega_writing@1`
- `omega_visual_planning@1`
- `omega_image_global_style@1`

Veja `omega_brain/README.md`.
